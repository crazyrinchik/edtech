# Совёнок

Платформа дополнительного образования для 1 и 2 класса: математика и русский язык
короткими занятиями. Три интерфейса в одном приложении — ребёнок, родитель, администратор.

Демо: https://sovenok-school.higgsfield.app

## Что умеет

**Ребёнок.** Карта тем с последовательным открытием, задания трёх типов (выбор варианта,
ввод ответа, сопоставление), мгновенная проверка, разбор ошибки словами вместо «неверно»,
проверочная работа с порогом 70% для зачёта темы, звёзды за пройденные темы,
мягкое напоминание об отдыхе через настраиваемый интервал.

**Родитель.** Отдельный взрослый интерфейс без анимаций: доля верных ответов, минуты
и занятия за неделю, пройденные темы, зоны риска (темы с долей верных ниже 70%),
история занятий, лимит времени и звук, управление подпиской, несколько детей в аккаунте.

**Администратор.** CRUD тем и заданий, DAU и WAU, конверсии (регистрация → первое занятие,
доля открывших родительский кабинет, доля оплативших), проблемные и популярные темы,
блокировка пользователей и выдача подписки вручную.

## Стек

- TanStack Start (React 19, SSR) + TanStack Router
- Cloudflare Workers как рантайм, Cloudflare D1 (SQLite) как база
- Vite, TypeScript, Tailwind
- Zod для валидации входных данных серверных функций

## Данные и приватность

- Аккаунт заводит взрослый. Согласия на обработку данных родителя и данных ребёнка
  собираются раздельно, факт и время фиксируются в таблице `users`.
- О ребёнке хранятся только имя, класс, аватар, ответы и время занятий.
  Почта, телефон и фотографии ребёнка не собираются.
- Пароли — PBKDF2-HMAC-SHA256, 100 000 итераций, случайная соль на пользователя.
- Сессии — HttpOnly-куки, срок 30 дней, сверка с таблицей `sessions` на каждом запросе.
- Профиль ребёнка доступен только своему родителю: проверка `requireOwnChild`
  стоит в каждой функции, принимающей `childId`.

## Первый запуск

Первый зарегистрировавшийся пользователь получает роль `admin` — заведите свой аккаунт
сразу после развёртывания. Учебный контент создаётся автоматически при первом обращении
(функция `ensureSeeded`), повторно не дублируется.

Промокоды для активации подписки на пилоте: `SOVENOK`, `PILOT2026`, `SEMYA`.

## Локальная разработка

```bash
cd app

```

## Перенос на собственный сервер

Приложение написано под Cloudflare Workers и D1. Для развёртывания на своей
инфраструктуре (например, при требованиях 152-ФЗ к размещению данных в России)
нужно заменить два места:

1. `src/lib/core.server.ts`, функция `db()` — вместо биндинга D1 подключить
   PostgreSQL или SQLite. Весь остальной код обращается к базе только через неё.
2. Синтаксис запросов. Используется `prepare().bind().first()/.all()/.run()` и `batch()`
   в стиле D1; при переходе на PostgreSQL заменяются плейсхолдеры `?` на `$1, $2`
   и метод `batch` на транзакцию.

Схема в `migrations/0002_sovenok.sql` написана на стандартном SQL и переносится
почти без правок. Сборка под обычный Node вместо Workers меняется в `vite.config.ts`.

Настройте регулярный дамп базы во внешнее хранилище: репликация диска защищает
от отказа железа, но не от ошибочной миграции или случайного удаления.
